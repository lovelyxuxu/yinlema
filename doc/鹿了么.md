# 鹿了么

## 是什么

webApp的形式，是一款辅助记录男性Masturbation行为，用于男性的自我健康管理的工具，底部导航菜单为：鹿了么、今日鹿么、身份；

## 技术栈

移动端，vue3

## 功能设计

### 鹿了么

Masturbation行为的记录表，统计维度可以切换，按天、按周、按月；

根据历史数据给出今日Masturbation值；

上方展示你已经xxx天没鹿（Masturbation）了，xxxx这种鼓励的话；

再此基础上你可以进行功能扩展，目的是提供用户数据分析功能，对用户进行积极鼓励；

### 今日鹿么

提供按钮随机给出用户今天Masturbation还是不Masturbation，随机结果下方要给对应的一些文案；

### 身份

可以调整今日鹿么的随机概率，可以根据角色切换的形式去切换概率，比如选择西格玛男人，随机到Masturbation的概率是1%
